# Presentation Outline (5-7 minutes)

1. **Problem (30 seconds):** Students often know a desired tech career but not the specific skills or project sequence to reach it.
2. **Live flow (3 minutes):** Create account, enter profile, select a role, generate a roadmap, show readiness/gaps, mark progress, and ask RAG Chat a question.
3. **AI proof (1 minute):** Explain the `SkillAnalyzer`, `CareerAgent`, two agent tools, local knowledge-base retrieval, and returned sources.
4. **Engineering proof (1 minute):** Show React dashboard, API Gateway, Auth Service, Python service, MongoDB, Docker Compose, Kubernetes YAML, Terraform, and CI workflow.
5. **Closing (30 seconds):** SkillForge turns career uncertainty into an affordable, trackable, grounded learning journey.
